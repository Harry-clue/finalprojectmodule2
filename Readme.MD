# Dictionary App

A simple web app to look up English words. Type a word to see its definitions, phonetic spelling, and pronunciation audio.

Built with HTML, JavaScript, Tailwind CSS, and the [Free Dictionary API](https://api.dictionaryapi.dev/api/v2/entries/en/).

## Run it

Open `index.html` in your browser.
